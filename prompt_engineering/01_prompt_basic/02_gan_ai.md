# AI Model

## 생성형 AI 개념과 아키텍처

#### 1. 생성형 AI의 정의와 차이

(프롬프트 엔지니어 용어)
- Prompt: AI 모델에게 특정 작업을 수행하도록 지시하는 입력 테스트나 명령어
- Prompting: AI 모델과 상호작용하기 위해 프롬프트를 작성하고 입력하는 행위
- Prompt Engineer: AI 모델의 성능을 최적화하기 위해 프롬프트를 전문적으로 설계하고 개발하는 직업
- Prompt Engineering: AI 모델로부터 원하는 결과를 얻기 위해 프름프트를 체계적으로 설계하고 최적화하는 분야

(생성형 AI 관련 용어)
- Generative AI: 텍스트, 이미지, 음성 등 새로운 콘텐츠를 생성할 수 있는 인공지능 기술
- LLM(Large Lnaguage Model): 방대한 텍스트 데이터로 훈련된 대규모 신경망 기반 언어 처리 모델
- Multimodal AI: 텍스트, 이미지, 음성 등 여러 형태의 데이터를 동시에 처리할 수 있는 AI 시스템

(기타 생성형 AI 관련 기술)
- 생성형 UI: 사용자 의도에 기반해 실시잔으로 동적인 화면을 생성하는 기술
-  LAM(Large Action Model): 소프트웨어/앱을 조작하여 디지털 행동을 수행하는 AI 모델
-  Physical AI: AI를 탐재해 물리적으로 움직이는 기계
-  Synthetic Data(합성 데이터): AI 알고리즘으로 생성한 학습용 데이터
-  XAI(Explainable AI): 설명 가능한 AI

#### 2. 주요 생성 모델 구조

(GAN)
- GAN: 두 개의 신경망이 서로 대립하며 발전. 생성자와 판별자로 구성

(VAE)
- VAE(Variational AutoEncoder): 입력 데이터를 잠재 공간(Latent Space)의 확률 분포로 인코딩한 후, 이를 샘플링하여 원본과 유사한 데이터를 생성하는 생성 모델. 변분 추론을 통해 학습
- Encoder: 고차원 입력 데이터를 저차원 잠재 공간으로 압축하는 신경망. 확률적 인코딩 수행
- Decoder: 잠재 공간의 벡터를 받아 원본 데이터 공간으로 복원하는 생성 네트워크
- Latent Space(잠재 공간): 복잡한 데이터를 핵심 특징만으로 표현한 간단한 공간. 각 데이터를 하나의 점이 아닌 확률 분표로 표현

## LLM의 구조

#### 1. 언어 모델의 발전과 토큰화
- LLM(Large Langauge Model): 방대한 양의 텍스트 데이터로 학습된 인공지능 모델. Large는 매개변수의 규모를, Langauge Model은 언어의 패턴과 구조를 학습하여 텍스트를 이해하고 생성하는 모델을 의미
- 사전학습: 대규모 텍스트 데이터로 다음 단어 예측 학습
- 미세조정: 특정 작업에 맞춘 추가 학습
- 강화학습: 인간 피드백 기반 선호도 학습

(LLM 한계)
- 환각(Hallucination)
- 맥락 길이 제한
- 편향성 문제
- 계산 비용

(LLM 활용)
1. 텍스트 생성 및 창작
2. 번역 및 요약
3. 코드 생성 및 디버깅
4. 고객 서비스
5. 교육 및 학습

#### 2. 어텐션 메커니즘의 원리
- 어텐션 메커니즘: 입력 데이터의 특정 부분에서 선택적으로 집중하여 정보를 처리하는 기법. 중요한 부분에 더 많은 가중치를 부여
- 셀프 어텐션: 입력 시퀀스 내의 모든 위치가 서로를 참조할 수 있게하는 메커니즘

#### 3. 파운데이션 모델과 태스크 특화 모델

- Foundation Model: 다양한 AI 응용의 토대가 되는 대규모 사전학습 모델을 의미. 하나으 ㅣ기반 위에서 여러 태스크를 수행할 수 있는 범용성을 갖춤
- Task-Specific Model(=Fine-tuned Model): 파운데이션 모델을 특정 업무나 도메인에 최적화한 모델. 파운데이션 모델에 추가 학습이나 조정을 가해, 특정 태스크에서 더 높은 성능과 효율성을 발휘하다록 만듬

## 생성형 AI 학습 및 최적화 기법

#### 1. 사전학습과 미세조정
- 사전학습: 레이블이 없는 대규모 텍스트 데이터에서 언어의 구조와 의미를 스스로 학습하는 과정
- 미세조정: 사전학습된 모델을 특정 작업에 맞게 재학습시키는 과정

#### 2. 인간 피드백 기반 강화학습(RLHF)
- RLHF(Reinforcement Learning from Human Feedback): 대규모 언어모델을 인간의 선호도와 의도에 맞게 정렬시키는 핵심 기술. 인간 평가자의 피드백을 활용

(RLHF 3단계 프로세스)
1) 지도학습 미세조정(SFT): 고품질의 시범 데이터를 수집. 이상적인 응답을 직접 작성하여 메세조정
2) 보상 모델 훈련(RM): 인간의 선호도를 학습하는 보상 모델을 구축. 평가자가 여러 응답에 순위를 매긴 것을 바탕으로 선호되는 응답 예측
3) 강화학습을 통한 최적화(PPO): 보상 모델을 활용하여 언어 모델 자체를 최적화. 보상 모델이 부여한 점수를 기반으로 모델의 파라미터를 업데이트.
- 과도한 최적화는 모델이 Reward Hacking(보상 해킹)을 학습하여 실제로는 품질이 낮지만 높은 점수를 받는 응답을 생성하게 만들 수 있음
