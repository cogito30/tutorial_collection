# AI Prompt

## 프론프트 구조 설계 및 패턴

#### 1. 프롬프트의 구성 요소와 설계 원리
- 프롬프트: AI 언어 모델에게 특정 작업을 수행하도록 유도하는 입력 텍스트
- 프롬프트 엔지니어랑: AI 언어 모델에게 원하는 결과를 얻기 위해 효과적인 지시문을 설계하고 최적화하는 기술

(프롬프트 구성요소)
1) 지시(Instruction): 명확한 작업 지시와 요구사항 전달
2) 맥략(Context): 배경 정보와 관련 상황 제공
3) 입력(Input Data): 처리한 구체적인 데이터
4) 제약조건(Constraint): 생성 결과물의 제한사항 설정
5) 출력 형식(Output Format): 원하는 결과물의 형태 지정

(프롬프트의 재료)
1) 명령하기: 명확한 동사와 목적어로 수행할 행동을 정의. ~해줘, ~하도록해.
2) 분석하기: 정보 파악 명령. ~ 분석해줘.
3) 변환하기: 동일한 정보를 다양한 목적과 독자층에 맞게 최적화. ~을 요약해줘, 핵심만 추출해줘.
4) 생성하기: 새로운 아이디어나 콘텐츠를 창출하도록 요청하는 명령을 작성할 때 쓰이는 단어. ~를 기반으로 ~을 생성해줘.
5) 대화하기: 질문과 응답을 반복하며 점진적으로 결과를 개선. 내가 쓸 계획서를 네가 대신 작성해줘.

#### 2.자언어 이해와 입력 기호

(NLP 개념)
- N-gram Model: 연속된 n개의 단어 또는 문자를 하나의 단위로 추출하여 분석하는 통계적 기법
- BPE(Byte Pair Encoding): 데이터에서 가장 빈번하게 등장하는 문자 쌍을 반복적으로 병합하여 서브워드 어휘를 구성하는 압축 기법
- Topic Modeling: 대량의 문서 집합에서 숨겨진 주제를 자동으로 발견하는 확률 기반 텍스트 분석 기법
- LSA(Latent Semantic Analysis): 선형대수의 특이값 분해(SVD)를 활용하여 문서와 단어의 숨겨진 의미 관계를 발견하는 기법

(단어 수준 임베딩 기법)
- Word2Vec(CBOW, Skip-gram): 단어의 의미를 주변 단어들과의 관계로 학습하는 방법
- Glove: 전체 말뭉치의 단어 동시 출현 통계를 미리 계산하고 이를 기반으로 임베딩을 학습
- ELMo(Embedding from Language Models): 양방향 언어 모델을 사용하여 문맥을 고려한 단어 표현을 생성. 문장 전체를 읽고 각 단어의 의미를 결정

(자연어처리 4단계)
1) Morphological Analysis(형태소 분석)
2) Syntax Analysis(구문 분석)
3) Semantic Analysis(의미 분석)
4) Pragmatic Analysis(화용 분석)

(프론프트 입력 기호)
- 마크다운: 제목 구분, 강조(굵게/기울임), 하이퍼링크(인라인/참조), 인용문(단일/중첩)
- XML 태그, 백틱, 삼중 백틱, 중괄호 등

## 효과적인 프롬프트 작성 원칙

#### 1. 명확성, 구체성 및 단계별 지시
- 명확성: 모호함 제거(추축 최소화), 직접적 지시(명시적 표현), 일관된 용어(동일한 용어)
- 구체성: 상세한 정보 제공(정확한 맥락 파악), 정량적 표현(측정 가능한 기준), 예시와 사례(추상적 개념을 구체적으로 표현)

#### 2. 프롬프트 기초 설계

(n-샷 프롬프팅)
- Zero-shot Prompting: 예시를 전혀 제공하지 않고 작업 설명만으로 모델에게 과제를 수행하도록 요청하는 방식
- One-shot Prompting: 하나의 예시를 제공하여 모델이 작업의 패턴과 형식을 파악하도록 돕는 방식
- Few-shot Prompting: 여러 개의 예시(2-5개)를 제공하여 모델이 작업의 패턴을 학습하고 새로운 입력에 적용하도록 하는 방식

- Semantic Filter Pattern: 출력 결과에 특정 기준이나 제약 조건을 적용하여 원하지 않는 내용을 걸러 내는 기법
- Feedback Loop Prompting: AI가 초안을 생성한 후 사용자의 피드백을 받아 반복적으로 개선해나가는 프롬프트 구조

(역할 부여)
- 전문가 역할 부여: 특정 분야의 전문 지식과 경험을 가진 인물로 AI를 설정
- 청자 지정: 응답 대상을 명확히 규정하여 설명의 수준과 방식을 조정
- 관점 설정: 문제를 바라보는 시각과 우선순위를 지정하는 방식
